# 六组易翘边薄板测试模型（STL）

版本日期：2026-09-05  
单位：mm  
STL 厚度：2.0 mm（按 0.20 mm 层高时对应 10 层）

## 结论与使用边界

本包提供 6 组同级候选：保留原五角星作为基准，另外 5 组分别突出长轴尖端、对角长臂、平行叉臂/深槽、曲边自由端、手性折臂等翘边特征。所有模型均为单一连通、无孔、无需支撑的薄板；投影面积统一为约 3020 mm²，最大包络接近 100 mm，以降低用料和尺度差异。

模型是否“易翘边”高度依赖材料和工艺。PLA、ABS/ASA、封闭环境、热床表面和风扇设置可能产生完全不同的排序；不要跨工况比较，也不要把本包的几何预筛选当作最终难度结论。
